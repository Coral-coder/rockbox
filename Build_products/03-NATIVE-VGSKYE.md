# Bare-metal native Rockbox (not in this kit)

This repository and **Build_products** are **hosted-only** (Rockbox under stock HiBy Linux).

For **native** bare-metal Rockbox on the Hifi Walker H2 / Eros Q family, use **vgskye**’s tree and docs:

| Resource | URL |
|----------|-----|
| **Source** | https://github.com/vgskye/rockbox |
| **BT + extra codecs branch** | https://github.com/vgskye/rockbox/tree/bt-extra-codecs |
| **Upstream wiki** | https://www.rockbox.org/wiki/ErosQNativeTroubleshooting |
| **Install overview** | https://www.rockbox.org/wiki/AIGOErosQK |

Native builds use target **`erosqnative`**, not `aigoerosq`. Do not mix native `rockbox.erosq` with the hosted binary in this folder.
